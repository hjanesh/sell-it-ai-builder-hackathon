What changed in this flow

Login moves to screen 05, after price is visible — the user has already seen value by then. The signup drop-off we feared vanishes.

Interest, both ways

Public listing captures buyers via the "I'm interested" tap. For buyers who messaged offline, the seller uploads a screenshot (screen 11) — AI parses names & numbers into the same CRM.

Dynamic pricing nudge

When interest-count outruns stock, the dashboard surfaces a tip to raise price for the next drop. Priya runs real pricing experiments without thinking about them.

The brand voltage

Cream canvas, dark CTAs, saturated single-color cards for feature moments (price picker, channel picker, demand tip). The warm palette is the main contrast against OLX, Marketplace, and generic listing tools.
